# Upload guide

1. Open GitHub and create/open the **public** repository named exactly `MOHENDRA-3850`.
2. This must be the profile repository whose name exactly matches your GitHub username.
3. Upload `README.md` and the complete `assets/` folder to the repository root (not the ZIP itself).
4. Commit the changes to the default branch.
5. Visit `https://github.com/MOHENDRA-3850` and check the result on desktop and mobile.

## Before publishing
- Confirm that the 2027 IISc selection wording is accurate and that you are comfortable making it public.
- Review contact details and all project/publication links.
- Replace any project link that currently points to the profile root with the exact repository URL when available.
- The generated banner is a visual artwork; do not rely on text baked into it for factual details. The README below it contains the editable text.
- GitHub README SVG rendering and animation can vary by viewer. The content remains readable in the static fallback.

## Files
- `README.md`: profile page.
- `assets/`: custom Arabian-tech themed SVG panels and generated hero artwork.
- `preview.html`: local preview.
